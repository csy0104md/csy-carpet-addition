# CSY Carpet Addition

[English](README.md) | **中文**

一个 Carpet 拓展（Carpet Addition），为 Minecraft 1.21 添加两条生存向规则：

- `magmaBlockConnectsRails` —— 岩浆块可以像铁轨一样连接周围的铁轨；
- `phantomWhiteHorse` —— 幻翼生成时可能骑着一只白马。

- Mod ID：`csy-carpet-addition`
- 源码仓库：<https://github.com/csy0104md/csy-carpet-addition>
- 开源协议：[MIT](LICENSE)

## 规则

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| `magmaBlockConnectsRails` | `false` | 岩浆块可以像铁轨一样连接其他铁轨：只在放置岩浆块时尝试连接一次；不改变岩浆块原版行为，只增加连接铁轨的特性 |
| `phantomWhiteHorse` | `false` | 幻翼生成时有概率骑着一只规则生成的白马：`true` 为默认 20%，`false` 完全关闭，也可以填 0~100 的整数（可带 `%`）自定义概率 |

## 岩浆块连接铁轨

开启 `magmaBlockConnectsRails` 后，岩浆块会像铁轨方块一样参与铁轨的连接判定。和它相邻的铁轨会像对面是铁轨一样朝它连接，包括：

- 东西南北四个方向（同一高度）；
- 斜上方、斜下方各一格（连成上坡 / 下坡）。

「铁轨 — 岩浆块 — 铁轨」会连成一条贯通的线路，多侧有铁轨时形成路口。形状用的是原版铁轨自己的连接逻辑（和铁轨连铁轨是同一套判断），和原版铁轨完全一致。

### 连接规则

**连接只在放置岩浆块的那一刻尝试一次。** 放下去时周围铁轨会按原版逻辑重算形状、连上岩浆块；之后岩浆块就不再参与铁轨的连接判定：

- 在**已有岩浆块旁边放铁轨**不会连上（铁轨按普通方块处理，形状不会指向岩浆块）；
- 已经连上的铁轨如果因为别的原因（红石更新等）重算形状，**连接可能会断开**；
- 想重新连上，破坏并重新放置岩浆块即可（只要放置时周围有铁轨，就会重新连一次）。

**连接到岩浆块的铁轨只会连岩浆块。** 被连上的铁轨不会再拐向旁边的其他铁轨，也不会把更远处的铁轨拉进来重连。例如在南北向铁路旁放岩浆块：那一格铁轨只会朝向岩浆块（变成东西向），南北两格的铁轨形状保持原样，不会被改成拐弯。和岩浆块在同一轴线上连着的铁轨（`铁轨 — 岩浆块 — 铁轨`，以及直线上的前后几格）形状不变，直线行驶不受影响；斜向的上坡 / 下坡连接也不变。

**刷新顺序和原版铁轨一致。** 岩浆块放置时刷新周围铁轨的顺序，用的是原版 `RailPlacementHelper` 判定连接时的顺序——北 → 南 → 西 → 东，每个方向先看同高度，再看上方一格，最后看下方一格。

**破坏岩浆块不会刷新周围的铁轨。** 铁轨会保留连接时得到的形状，直到有其他变化（比如红石信号、铁轨自身的更新）让它重新计算。

**原版行为完全不变。** 岩浆块本身没有任何改动：踩上去的伤害、上方的气泡柱都和原来一样；关闭规则时行为与原版完全一致。

**客户端兼容。** 不新增、不修改任何方块状态（不给岩浆块加属性，方块状态 id 不移位），客户端不安装本 mod 也可以正常游玩（连接形状由服务端计算并同步）。

## 幻翼生成白马

幻翼生成时，`phantomWhiteHorse` 会按设定的概率抽一次，抽中就在幻翼身上生成一只白马骑着它（和蜘蛛骑士一样是骑乘关系，会跟着幻翼一起移动）。

### 规则取值

| 取值 | 含义 |
| --- | --- |
| `false` | 完全关闭规则（默认） |
| `true` | 默认 20% 的概率 |
| `0` ~ `100` | 自定义百分比概率，可以带 `%`：`35` 和 `35%` 等价 |

`0` 和 `false` 一样会关闭规则，但**不会被合并成 `false`**：值仍然保持为 `0`，这样能看出规则是被 `false` 关掉的还是被自定义的 0% 关掉的。不是 `true`、`false` 或 0~100 整数的写法在游戏内会被拒绝，并给出提示。

### 白马

- 是没有斑纹的白马，和普通马一样**可以驯服**（用原版方式反复骑乘即可）；
- **速度和跳跃都是马的最低值**（移动速度 `0.1125`，跳跃强度 `0.4`）；
- 死亡时**必定掉落一瓶名为“白粥”的牛奶**（带这个名字的牛奶桶，100% 掉落，不受抢夺影响）；
- 带有实体标签 `csy_phantom_white_horse`（`/data get entity <马> Tags` 可以查看），用来标记它是规则生成的马。

**不影响原版自然生成的马。** 只有规则为幻翼生成的那只马具备以上特性；自然生成（以及命令、刷怪蛋、繁殖等方式生成）的马，颜色、属性、驯服、掉落全都保持原版——原版马的战利品表完全没有改动，只有带上面那个标签的马才会掉牛奶。规则只在幻翼生成时才抽概率，关闭规则时没有任何变化。

**客户端兼容。** 没有新增方块、物品或实体，“白粥”就是一个改了名字的普通牛奶桶，同样不需要客户端安装 mod。

## 适配版本

- Minecraft 1.21
- Fabric Loader 0.15.11 及以上
- Carpet 1.4.147（对应 `1.21-1.4.147+v240613`）
- 本 mod 与 Carpet 一起放进服务端的 `mods` 文件夹即可；客户端可以不装（两条规则都不需要客户端 mod）。
