# CSY Carpet Addition

[English](README.md) | **中文**

一个 Carpet 拓展（Carpet Addition）：让岩浆块可以像铁轨一样连接周围的铁轨，并让幻翼生成时可能骑着一只白马。

- Mod ID：`csy-carpet-addition`
- 源码仓库：<https://github.com/csy0104md/csy-carpet-addition>
- 开源协议：[MIT](LICENSE)

## 规则

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| `magmaBlockConnectsRails` | `false` | 岩浆块可以像铁轨一样连接其他铁轨：只在放置岩浆块时尝试连接一次；不改变岩浆块原版行为，只增加连接铁轨的特性 |
| `phantomWhiteHorse` | `false` | 幻翼生成时有概率骑着一只规则生成的白马：`true` 为默认 20%，`false` 完全关闭，也可以填 0~100 的整数（可带 `%`）自定义概率 |

## 岩浆块连接铁轨（`magmaBlockConnectsRails`）

开启后，和岩浆块相邻的铁轨都会像对面是铁轨一样朝岩浆块连接，包括：

- 东西南北四个方向（同一高度）；
- 斜上方、斜下方各一格的方向（会连成上坡/下坡）。

因此「铁轨 — 岩浆块 — 铁轨」会连成一条贯通的线路，岩浆块四周有铁轨时也会各自朝它连接，形成路口。

连接使用的是原版铁轨自己的连接逻辑（和铁轨连铁轨走的是同一套判断），所以形状和原版铁轨完全一致。

**连接只在放置岩浆块的那一刻尝试一次**：放下去的时候周围铁轨会按原版逻辑重算形状、连上岩浆块；之后岩浆块就不再参与铁轨的连接判定了。也就是说：

- 在**已有岩浆块旁边放铁轨**不会连上（铁轨按普通方块处理，形状不会指向岩浆块）；
- 已经连上的铁轨如果因为别的原因（红石更新等）重算形状，**连接可能会断开**；
- 想重新连上，破坏并重新放置岩浆块即可（只要放置时周围有铁轨，就会重新连一次）。

**连接到岩浆块的铁轨只会连岩浆块**：被连上的铁轨不会再连接（拐向）旁边的其他铁轨，也不会把更远处的铁轨拉进来重新连接。例如在一条南北向铁路旁边放岩浆块：那一格铁轨只会朝向岩浆块（变成东西向），南北两格的铁轨形状保持原样，不会被改成拐弯。和岩浆块在同一轴线上连着的铁轨（`铁轨—岩浆块—铁轨`，以及直线上的前后几格）形状和原来一致，直线行驶不受影响；斜向的上坡/下坡连接也不变。

**更新顺序也和原版铁轨一致**：岩浆块放置时刷新周围铁轨的顺序，用的是原版 `RailPlacementHelper` 判定连接时的顺序——北 → 南 → 西 → 东，每个方向先看同高度，再看上方一格，最后看下方一格（也就是原版 `getNeighboringRail` 的检查顺序）。

**客户端兼容**：本 mod 不新增或修改任何方块状态（不给岩浆块加属性，方块状态 id 不移位），客户端不安装本 mod 也可以正常游玩（铁轨的连接形状由服务端计算并同步）。

**破坏岩浆块时不会刷新周围的铁轨**：铁轨会保留连接时得到的形状，直到有其他变化（比如红石信号、铁轨自身的更新）让它重新计算为止。放置岩浆块的瞬间会刷新一次，让周围铁轨连上。

岩浆块的原版行为完全不变（踩上去的伤害、上方的气泡柱都不受影响）。关闭规则时行为与原版完全一致。

## 幻翼生成白马（`phantomWhiteHorse`）

幻翼生成时会按设定的概率抽一次，抽中就在幻翼身上生成一只白马骑着它（和蜘蛛骑士一样是骑乘关系，会跟着幻翼一起移动）。

### 规则取值

| 取值 | 含义 |
| --- | --- |
| `false` | 完全关闭规则（默认） |
| `true` | 默认 20% 的概率 |
| `0` ~ `100` | 自定义百分比概率，可以带 `%`：`35` 和 `35%` 等价 |

`0` 和 `false` 一样会关闭规则，但**不会被合并成 `false`**：值仍然保持为 `0`，这样能看出规则是被 `false` 关掉的还是被自定义的 0% 关掉的。不是 `true`、`false` 或 0~100 整数的写法在游戏内会被拒绝，并给出提示。

### 白马

- 是没有斑纹的白马，和普通马一样**可以驯服**（用原版方式反复骑乘即可）；
- **速度和跳跃都是马的最低值**（移动速度 `0.1125`，跳跃强度 `0.4`）；
- 死亡时**必定掉落一瓶名为“白粥”的牛奶**（带这个名字的牛奶桶，100% 掉落，不受抢夺影响）；
- 身上带有实体标签 `csy_phantom_white_horse`（`/data get entity <马> Tags` 可以查看），用来标记它是规则生成的马。

**不影响原版自然生成的马。** 只有规则为幻翼生成的那只马具备以上特性；自然生成（以及命令、刷怪蛋、繁殖等方式生成）的马，颜色、属性、驯服、掉落全都保持原版——原版马的战利品表完全没有改动，只有带上面那个标签的马才会掉牛奶。规则只在幻翼生成时才抽概率，关闭规则时没有任何变化。

这条规则同样不需要客户端安装 mod：没有新增方块、物品或实体，那瓶“白粥”就是一个改了名字的普通牛奶桶。

## 开启方式

游戏内：

```
/carpet magmaBlockConnectsRails true
/carpet phantomWhiteHorse true
/carpet phantomWhiteHorse 35
```

或者写进服务端的 `config/carpet.conf`：

```
magmaBlockConnectsRails true
phantomWhiteHorse true
```

## 构建

```
gradlew build
```

产物在 `build/libs/csy-carpet-addition-<version>.jar`，放进服务端（或客户端）的 `mods` 文件夹即可，需要同时安装 Carpet。

## 适配版本

- Minecraft 1.21
- Fabric Loader 0.15.11 及以上
- Carpet 1.4.147（对应 `1.21-1.4.147+v240613`）

## 实现说明

原版铁轨的连接判断在 `RailPlacementHelper` 里：

- `getNeighboringRail` / `isVerticallyNearRail` 只认真正的铁轨方块；
- `canConnect` 决定某个方向能否接上；
- `RailBlock#updateBlockState` 只有在「发出红石信号的方块更新且周围铁轨数为 3」时才会重算形状。

所以本 mod 做了这几件事：

1. `RailPlacementHelper#getNeighboringRail` 找不到铁轨时，把岩浆块也当成一个「邻居铁轨」返回（用一个动力铁轨状态构造 helper），因为岩浆块没有 shape 属性，不能直接当成铁轨方块；
2. `RailPlacementHelper#isNeighbor(BlockPos)`：岩浆块的 helper 认为任何水平相邻的位置都是它的邻居，所以它会朝四周连接；
3. `RailPlacementHelper#computeRailShape`：对岩浆块的 helper 直接取消，保证任何时候都不会把 shape 写回世界（否则岩浆块会被铁轨方块替换掉）；
4. `AbstractRailBlock#isRail(World, BlockPos)` 把岩浆块也当作铁轨，用于上坡/下坡判定和 `getNeighborCount`；
5. 岩浆块被放置时，主动让可能连上它的 12 个位置上的铁轨重算形状（因为原版铁轨会忽略非红石信号方块的更新），顺序按原版铁轨的判定顺序：北 → 南 → 西 → 东，每个方向 同高度 → 上方 → 下方；
6. 第 1、2、4 条**只在第 5 步执行期间生效**（`MagmaRailUtils` 里一个「正在连接」标记，`isConnecting()`）：所以岩浆块只在放置的那一刻参与铁轨连接判定，之后就是普通方块——在已有岩浆块旁放铁轨不会连上，铁轨自身重算形状时也不再考虑岩浆块；
7. `RailPlacementHelper#canConnect(BlockPos)`：正在连接岩浆块的铁轨，只有朝向岩浆块的方向才算连接，其他方向（哪怕有别的铁轨）直接返回 false——所以它只会连岩浆块，不会拐向旁边的铁轨；同时 `computeRailShape`（原版用来把连接推给相邻铁轨的连锁重算）在「正在连接」期间全部跳过，连接不会扩散到第二格的铁轨；
8. `onBlockAdded` 只在**方块真正被放置**时执行第 5 步：原版 `WorldChunk.setBlockState` 在同方块换状态时也会调用 `onBlockAdded`，所以只有真正的放置才会触发连接（判断方式和原版铁轨 `AbstractRailBlock#onBlockAdded` 一致）；
9. 岩浆块被破坏时**不做**第 5 步，因此周围铁轨的形状保持原样；
10. 岩浆块本身的方块、行为一律不改。

幻翼白马部分用了三个 hook：

11. `PhantomEntity#initialize`（TAIL）：在这里抽概率并直接把马建出来，在幻翼加入世界之前就挂在幻翼身上（和蜘蛛骑士生成骷髅的方式一样），保证第一刻就带着骑手；
12. 用 `@Invoker` 调用私有的 `HorseEntity#setHorseVariant(HorseColor, HorseMarking)`，把 `initialize` 随机出来的颜色强制改成白色、无斑纹；
13. `AbstractHorseEntity#dropInventory`（TAIL）：只有带有 `csy_phantom_white_horse` 标签的马才会掉名为“白粥”的牛奶——原版马的战利品表完全没动，原版马也不会带这个标签。
